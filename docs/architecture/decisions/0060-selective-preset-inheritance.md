# 0060: Selective preset inheritance for layout rebinding

A matched text or shape-text placeholder can reset individual run, paragraph and frame declarations while retaining other local style declarations. The element retains its named preset and records the bypassed preset properties in `textStylePresetReset`. Normalization applies remaining preset properties over the target placeholder, then local declarations. Origins follow the same selection. This keeps unrelated preset properties and theme references live instead of copying effective values into local styles.

Run properties are independently selected, including separate Western, East Asian and complex-script font slots and color opacity. Script-font maps can be reset as a whole or by supported script key; a whole-map null barrier expands to retain the other clears and keeps its original preset source attribution. Paragraph bullets and autofit are atomic whole-property operations. Frame margins can be reset as a whole or by side; scalar declarations expand to preserve the other sides, while origin reporting still points to the original scalar preset. Local declarations added after the reset still win. A whole-text reset removes the preset and this selector. Detached, unmatched and ordinary elements do not have selective resets applied. Invalid selector values are validation errors. Table-cell styling, authored fields, native-template projection, and general transformed geometry remain open.
