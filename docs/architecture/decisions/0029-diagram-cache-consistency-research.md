# ADR 0029: Explicit diagram-cache dependency and publication research

Status: private executable research, 2026-10-26. Advances ADV-03.7.1/.7.2 and ADV-02.1.3.3; no public cache/native/source-write admission.

## Decision and ownership

Introduce a small format-owned [cache session](../../../scripts/research/diagram-cache-session.mjs) that captures explicit dependency snapshots and stages validated byte candidates. Core/IR and existing public Parser preview/save APIs remain unchanged. A newly imported cache remains unknown even if its bytes happen to match a previously managed artifact. Source-only cached preview remains a separate existing fallback contract; this write/reuse protocol does not forbid that read-only fallback.

The dependency snapshot binds exact owner/layout, coverage, generator version, environment key, frame size/rotation/flips and sorted unique role/id/SHA-256 descriptors. Exactly one data/layout/colors/style descriptor is required; complete coverage also requires theme evidence. Additional theme/resource descriptors are explicit. Translation is outside this local-cache input; size/transforms are captured. Equal descriptor sets ignore array order; all other changes are exact, with no inferred XML/visual/transform equivalence.

Coverage and digests are **supplied claims**, not proof of a complete OOXML dependency closure. The session performs no filesystem/network read, font resolution or native app operation. The owning adapter must derive the complete footprint, including themes/fonts/resources, before using complete. Arbitrary callbacks are trusted application code; a validator returning true is not independent evidence by itself. The browser integration supplies an actual independent DOM validator for a specifically named owned geometry-only SVG profile. Those SVG bytes are never written into a native DiagramML cache part.

## States and resolution

| State | Meaning |
| --- | --- |
| missing | No cache bytes |
| empty | Explicit zero-length source payload; not a verified render |
| unknown | Source bytes associated with the captured input but no managed validation witness |
| invalidated | Present cache's captured dependencies differ from current input; conservative protocol invalidation, not proof of a visible defect |
| managed-current | Independently validated through the supplied callback and committed for the exact current dependency snapshot |

Managed-current is scoped to that generator/validator/profile. It is not native compatibility, visual fidelity, complete semantic equality or cache freshness for arbitrary imported Office content. Serialized payload bytes do not serialize the session's witness. Returning to an earlier exact dependency snapshot can make a retained managed witness current again; unverified source bytes only return to unknown. Revision checks still reject old plans after an input change/revert (ABA).

The caller explicitly chooses block, invalidate or rebuild. A managed-current cache stages reuse. Otherwise block returns a located state reason; invalidate stages cache omission; rebuild requires complete declared dependency coverage and explicit generation/validation callbacks. Rebuild results remain staged until commit. The session does not remove original OPC parts or relationships; source closure/reconciliation authority remains separately gated under [ADR0006](0006-source-relationship-closure.md) and preservation-save contracts.

## Atomicity and lifecycle

Generation and validation receive detached snapshots and a cooperative abort signal. Generated bytes are copied before validation; the validator receives a separate copy, and differing bytes at validation completion reject. Commit requires an authentic, unconsumed plan from this session, the captured input revision and the captured cache-publication epoch. Cross-session/forged/released/consumed/stale/aborted/disposed plans cannot publish. A later cache publication also invalidates earlier plans even for unchanged input. Read returns detached bytes; commit publishes only the cache session's internal selection.

This is **not** a filesystem/package/document transaction. An owning application must serialize package/file publication and state commit and validate the actual candidate package. No cross-resource compare-and-swap or source-save authority is provided. Generator/validator failures, mutation, cancellation and exceeded payload limits preserve the previously selected cache. Input update aborts obsolete work. Dispose immediately removes the external abort relay, aborts the child and releases session-held buffers/plans. A callback ignoring cancellation can delay preparation settlement; the session does not terminate arbitrary code and remains busy until the callback settles.

Only one generator runs at once. At most four prepared plans are retained by default; callers must release abandoned/stale plans or dispose the session. Bounds also cap 4,096 dependency descriptors, 1,000,000 serialized snapshot bytes and 8,000,000 bytes per cache payload. Escaped JSON/UTF-8 bytes are charged incrementally before full-snapshot concatenation. Callback CPU/IO cost and whole-process memory are outside these per-operation bounds. Native Uint8Array byte-length access prevents an overridden byteLength property from bypassing the payload limit. No new package/dependency is introduced.

## Evidence

Seven pure groups test source-state distinctions, policy decisions, staged publication, detached bytes, every dependency category and environment/frame/generator invalidation, exact input restoration versus stale ABA plans, publication epochs, cross-session ownership, generation/validation failures and mutation, true payload size bounds, cancellation/disposal/listener cleanup, async validation races, explicit plan quotas and exact snapshot-byte limits and escaped control-character amplification. A 120-round seeded state-machine oracle independently checks update, block/omit/rebuild, release, failure, stale-plan and commit outcomes. One browser integration creates an actual owned Cycle geometry-only SVG cache, independently parses its metadata/circles/edges and verifies hand-calculated square packing. It rejects old payloads for new source/color dependencies, aborts stale generated work, validates a replacement, and proves that a new session still treats serialized managed bytes as unknown.

The separate [Cycle spacing observation](../../../scripts/research/cycle-spacing-observation.mjs) and [updated native evidence](../../testing/smartart-cycle-layout-evidence.json) constrain layout admission. Four pure groups and independent Python fit/quantization calculations show native gap ratios near 0.504237689 (3 nodes), 0.501699392 (4), 0.503197971 (5). Ring reconstruction residuals are below one EMU, but nearest-EMU rounding of the proposed layout still leaves roughly 0.137–0.236-point mismatches. A theme-change pair changes explicit circle stroke width from 1.5 to 1 point while retaining exactly the same circle boxes. These observations exclude simple rounding or an assumed universal half-stroke inset as a demonstrated correction. They do not establish a universal native spacing algorithm; inferred ratios remain descriptive and are not patched into the solver.

Native cache generation, intentionally stale real-cache application behavior, complete source dependency derivation, accepted layout/font/paint policies, whole-package atomic updates and public admission remain open. Parent tasks remain incomplete.
