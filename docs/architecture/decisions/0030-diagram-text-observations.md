# ADR 0030: Opt-in direct diagram text observations

- Status: accepted experimental inspection contract; native cache generation/admission remains open
- Date: 2026-10-26

## Problem

Explicit source/cache model associations establish references, not text agreement or cache freshness. A valid stored cache can display different characters from its content point. Inspection needs bounded, located observations without changing default output, preview policy or editing authority.

## Decision

Parser owns `diagramTextComparison: "direct-paragraphs"` and the detached readonly text report. It compares exact paragraph vectors only for explicit unique content/assistant targets, allowing an agreeing recognized presentation association. Incomplete graphs/maps, fields and unknown text structures are unavailable/source-only rather than guessed. Raw indices stay scoped to their source part. All freshness values remain unknown. No OOXML metadata enters Core/Layout/Renderer and no new package/dependency is introduced.

Use the existing cumulative diagram work/finding limits, charging scalar characters and repeated comparisons as well as raw tree indexing. Capture the option before byte/file awaits and preserve it for actual-candidate reprojection. Keep cached preview and preservation write permissions unchanged. The [API contract](../../api/diagram-text-comparison.md) defines exact coverage.

## Evidence and consequences

Seven focused groups cover both dialects, exact paragraph/Unicode boundaries, ambiguous targets, unavailable structures, shared owners, budgets/cancellation and option capture/save behavior. Three integration groups independently derive text/indices with browser DOM, compare Node/ESM/global reports, retain all non-slide payloads across three unrelated edits, and check file-import capture. Installed consumers exercise the new type/literal option.

The [15-case corpus](../../testing/smartart-stale-cache.md) transforms selected text independently in three retained PowerPoint-produced diagrams. Python ZIP/XML checks changed parts; PyMuPDF observes named LibreOffice direct/reopened PDFs. All fifteen save/reopen operations complete. Data-only changes remain in source data while old cache characters are displayed; cache-only changes display the cache marker. Equal characters still cannot certify geometry/style freshness. Subsequent [ADR0031](0031-native-stale-cache-policy.md) adds PowerPoint UI conflict/re-layout/repeated-rebuild evidence; family-wide policies remain unadmitted; third-party artifacts stay local pending redistribution admission.

ADV-03.7 and family admission remain open. This is a direct-character diagnostic, not a cache regeneration, source-save or universal semantic text-ownership contract.
