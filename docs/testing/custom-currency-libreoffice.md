# Synthetic custom currency resaves

The [retained input](../../tests/fixtures/custom-currency-source.pptx) was created by PPTKit and then manually changed from three string values to `vt:cy` values `1.2500`, `0.1000` and `-12.5000`. These are synthetic inputs, not currency properties authored by an application. Microsoft describes `vt:cy` as a currency variant with exactly four fractional digits in its [Open XML documentation](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.varianttypes.vtcurrency?view=openxml-3.0.1). This experiment does not validate the full `ST_Cy` lexical space, ranges or native currency editing.

PPTKit reports the three values as uninterpreted and does not project them to Core. A byte-identical no-op and a source-preserving edit of the separate `Control` string retain all three source elements. The [automated test](../../packages/pptx-parser/test/custom-property-currency.test.mjs) checks the fixture and edited output hashes, verifies three unrelated edits/reopens and compares all non-target package payloads. It does not claim semantic currency import or editing.

LibreOfficeDev 26.8.0.0.alpha0 headless PPTX resaves of both the unchanged and PPTKit-edited branches dropped all three currency properties on the first resave; the separate control string remained. Two further resaves continued without the currency elements. The [evidence](custom-currency-libreoffice-evidence.json) records the producer, source hash and package inventories. An independent XML scan checks all XML and relationship parts for transitional `vt:cy` elements. Outputs of the producer experiment are temporary and not distributed; the record is an observation, not independent proof that the producer was run. It does not establish behavior of other versions, PowerPoint, native UI editing, or any other currency value.

To reproduce, run `pnpm run build:browser`, install the named LibreOfficeDev build as `soffice`, then run `python3 scripts/research/probe-custom-currency.py`. The script uses isolated temporary profiles and prints a new JSON record; zip timestamps and output hashes may vary. No external links or macros are executed by PPTKit. Do not generalize PPTKit's preservation of its source input to a file that another producer has already stripped.
