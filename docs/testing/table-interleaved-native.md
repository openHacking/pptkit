# Interleaved table saves after LibreOffice resave

This separate headless experiment starts from the named LibreOfficeDev 26.8.0.0.alpha0 output retained by the [earlier table-save experiment](table-save-evidence.json). That application output had already removed the orphan, the injected opaque table extension and the embedded chart workbook. It is not the original PPTKit candidate and is not evidence of preservation of those lost inputs.

Three cycles interleave PPTKit `text-runs-v3` edits of two existing table anchors with LibreOffice headless PPTX resave; each next PPTKit cycle imports the immediately preceding native output. Independent ZIP/XML checks confirm that each PPTKit candidate changes only the two selected character atoms in one slide payload, with all other payloads identical to that cycle's input. The named physical merge grid, unedited control cells, note content, image bytes and chart cache values remain present. The chart workbook is absent from the starting native input and is not restored.

The native application changes the unedited shared image's width and height by **−360 EMU each per resave** in this named sample. Candidate-versus-resaved native PDFs have different first-page pixels in all three cycles; the second page pixels match, but image records differ on both pages. Text extraction locates both selected edits and control text; this is not complete visual equivalence. The [independent oracle](../../scripts/research/oracles/table-interleaved-native.py) checks both source and native stages, PDF text/pages, exact PPTKit candidate differences, original-candidate/native provenance, image dimensions and eleven corrupted cases. The [producer](../../scripts/prepare-table-interleaved-native.mjs) and [native-reopen PDF runner](../../scripts/inspect-table-native-reopens.mjs) reproduce the headless workflow; the source digest and retained artifacts are listed in [the evidence](table-interleaved-native-evidence.json). A second run reproduced the first candidate and all reports byte-for-byte and the six slide XML trees semantically; native ZIP byte identity is not claimed. [Parser evidence](table-interleaved-native-parser-evidence.json) covers seven source/candidate/native packages across Node, browser ESM and global with twenty-one exact no-op saves.

The experiment does not exercise an interactive application UI, establish PowerPoint behavior, validate arbitrary source references or close the table structural-edit and native-fidelity gates.
