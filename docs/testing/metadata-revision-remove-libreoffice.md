# Revision removal: LibreOfficeDev observation

The hash-checked PPTKit control has revision 7, title `Original title`, creator `Sentinel Author` and one keyword value `alpha, beta`. PPTKit's `metadata-revision-remove-v16` explicitly removed the revision element in an edited copy. Independent ZIP/XML checks confirm that only the core metadata part changed and all bytes outside that element stayed identical.

LibreOfficeDev 26.8.0.0.alpha0 headlessly resaved both branches three times. The control retained revision 7. On the first save, LibreOffice wrote revision `0` into the edited branch, where the source element had been absent, and retained it through the third save. This differs from PPTKit's normalized default of 1 for an absent revision. Both branches kept the title and creator, and their keyword changed from `alpha, beta` to `alpha beta` on the first save. These are observations of one synthetic Transitional file, not a general compatibility guarantee.
