# Core property insertion: PowerPoint observation

One source file from the [LibreOffice comparison](core-insert-libreoffice.md) contains four newly inserted properties: title `PPTKit Presentation`, empty subject, description `Inserted & 中文`, and language `fr-FR`. PowerPoint 16.104 opened it and produced three successive saved copies. Each copy was closed and reopened, and its single slide's `Metadata control slide` text was observed in the accessibility tree. No repair dialog was observed during these opens. The first Save As was invoked through PowerPoint scripting; subsequent saves and reopens used the application interface.

The [retained record](core-insert-powerpoint-evidence.json) and `python3 scripts/research/verify-core-insert-powerpoint.py` check ZIP integrity, source isolation, the four values, creator, keywords, revision and slide text. Those values remained present in all three saves. PowerPoint added last-modifier and modification-time properties, so source-to-output metadata is not byte-identical. The ZIP evidence does not independently attest the interface observations; screenshots or independent UI witnesses were not retained. The sample does not establish metadata UI editing, general property fidelity, other PowerPoint versions or other source shapes. Artifacts under `.tmp` are local.
