# Internal native bubble export probe

This experiment inserts a native 2D bubble chart and matching workbook into a scatter-generated carrier, retaining its chart relationship and two numeric axes. This original experiment predates the public API. Use the [bubble authoring API](../api/chart-bubble.md) for fresh export and SVG preview. The internal writer emits dense finite X and Y coordinates and strictly positive sizes; it shares the existing numeric and string cache writers. See the OOXML [bubble chart](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.charts.bubblechart?view=openxml-3.0.1) and [series](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.charts.bubblechartseries?view=openxml-3.0.1) contracts.

The [evidence](bubble-export-probe-evidence.json) records stable LibreOffice 26.8.2.2 on macOS arm64. The source and native resave both render three bubbles. Independent PDF path measurements verify that sizes 1, 9 and 4 yield approximate diameter ratios 1:3:2 in this chart. The native save retains all three numeric coordinate/size streams but removes the embedded workbook and its external-data declaration. This is headless evidence for this package only; interactive editing, repair dialogs, PowerPoint and other chart profiles remain untested.

After building, run [the probe generator](../../scripts/prepare-bubble-export-probe.mjs) with an optional output directory (default `.tmp/bubble-export-probe`). With distinct LibreOffice profiles, render `bubble.pptx` into `pdf/`, resave it using the Impress PowerPoint XML filter into `saved/`, and render that saved file into `reopened/`. Record the application's `--version` output in `version.txt`. Run [the independent verifier](../../scripts/research/verify-bubble-export-probe.py) with the output directory and PyMuPDF available; it checks raw chart XML, worksheet cells and the two rendered PDFs.

The [public API run](bubble-public-probe-evidence.json), generated with `--public`, produced a byte-identical source for this specimen. A fresh native save/reopen repeated the three observed sizes and the same workbook loss. Pass `--public` after the directory argument to label this run when generating its verification record.

The [CLI source-edit observation](bubble-source-save-native-evidence.json) begins with that same public package, uses a v4 manifest to change the second blue point from `(4, 4, 9)` to `(5, 5, 16)`, and reopens the edited PPTX in stable LibreOffice. Using the two unchanged bubbles as fixed-axis reference points, PDF measurements locate the edited centre at approximately `(5, 5)` and its diameter at four times the smallest bubble. The native resave and reopen repeat that result and retain the numeric caches, but remove the workbook. The [verifier](../../scripts/research/verify-bubble-source-save-native.py) independently compares both ZIP levels and PDF geometry in the retained directory. This exercises the CLI save and native rendering; LibreOffice's Data Table and PowerPoint were not used for the edit.
