# Synthetic exact currency source-save comparison

The input is the [retained synthetic fixture](../../tests/fixtures/custom-currency-source.pptx), created by PPTKit and manually modified to contain three `vt:cy` variants. The original values are `1.2500`, `0.1000` and `-12.5000`; the last is a nonconforming negative control under both published ST_Cy schemas, as explained in the [original currency experiment](custom-currency-libreoffice.md). These values were not authored in a native application.

The explicit `exact-save-v2` currency profile and `scalar-v1` source-save profile changed the first value from `1.2500` to `0.5000`. An independent ZIP comparison found only `docProps/custom.xml` changed; the other two currency values and the `Control` string remained. The source SHA-256 was `7da28fe0e4d9f8064495d0e6abce455c3a64c494c0cce4ab3b376f0a9d345657`, and the PPTKit-edited file SHA-256 was `2bd2025ac4ce8239585814648578222e3f874e7d72748162932f0645a3cead6a`. The [automated test](../../packages/pptx-parser/test/custom-property-currency-save.test.mjs) reconstructs this exact edit and checks both hashes and changed parts.

LibreOfficeDev 26.8.0.0.alpha0, in isolated headless profiles, resaved the original and edited inputs separately three times. On the first resave in both branches, all three currency properties disappeared; the unrelated `Control` string remained, and later resaves did not restore them. An independent XML scan of every XML and relationship part found no transitional `vt:cy` elements in those outputs. The [record](custom-currency-save-libreoffice-evidence.json) includes the producer version and per-round inventories. Producer outputs were temporary and are not retained, so this record alone is not independent proof that the producer was run. This result concerns only this synthetic fixture and version; it does not establish PowerPoint, native authoring or interactive editing behavior.

To reproduce, run `pnpm run build:browser` and `python3 scripts/research/probe-custom-currency-save.py` with the named LibreOfficeDev version available as `soffice`. Output ZIP metadata and hashes can vary between environments. Do not infer currency preservation through LibreOffice from PPTKit's source-save behavior.
