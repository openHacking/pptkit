# APNG preview: scoped Chromium observation

On 2026-10-27, bundled Chromium `149.0.7827.55` displayed the [two-frame Pillow fixture](../../tests/fixtures/two-frame-apng.png) in three contexts: PPTKit's inline SVG, the same SVG used as an HTML image, and the APNG used directly as an HTML image. The [probe](../../scripts/probe-apng-browser.mjs) took ten screenshots per context at roughly 60 ms intervals. The [independent pixel inspector](../../scripts/research/oracles/apng-browser-probe.py) recorded sample point `(400, 250)` and hashes in [evidence](apng-browser-observation.json). It found red `(255, 0, 0)` and composited purple `(127, 0, 128)` in all three contexts. Replacing every inline screenshot with the first frame was rejected by the inspector.

The recorded times are measured **before** each screenshot request, not exact capture or presentation times. Screenshot hashes alone do not prove browser provenance. This observation demonstrates two sampled colors in this one Chromium build, not precise timing, continuous playback, other browsers, PowerPoint, or all SVG host contexts. Probe artifacts remain under `.tmp/apng-browser-probe-01` while available. To reproduce, generate `preview.svg` with `scripts/prepare-apng-probe.mjs`, copy it to a new output directory, run the browser probe, then run the inspector. The producer should be run in an empty directory to avoid overwriting screenshots.
