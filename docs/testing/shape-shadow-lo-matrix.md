# Shape shadow opacity matrix: LibreOfficeDev observation

This is a scoped observation, not a PowerPoint acceptance result. The input has 25 separate slides covering shape and shadow opacities of 0, .25, .5, .75 and 1. Each slide has one opaque-red authoring fill whose effective opacity is the shape opacity, an unblurred black outer shadow, and a 100 pt rightward offset. The sample point `(180, 90)` lies inside the shadow and outside the shape. The [inspection script](../../scripts/research/oracles/shape-shadow-matrix.py) checks the source XML values before reading the pixel. Its `analyticProductGray` is an arithmetic comparison, not a measured browser pixel.

On 2026-10-27, LibreOfficeDev `26.8.0.0.alpha0 2c87e51eeaa2b413ff4ae097b2705eea1995d8e5` exported the PPTX to PDF; `pdftoppm` rasterized it at 72 dpi. The retained [evidence](shape-shadow-lo-matrix-evidence.json) contains the 25 measured grayscale pixels and hashes of the input, PDF and raster pages. The observed working artifacts are in `.tmp/shape-shadow-matrix-01`; hashes alone do not guarantee their retention or prove a PowerPoint result.

For example, shape opacity .25 and shadow opacity .25 gave gray 191, while the simple product model gives 239. At shape opacity .5 and shadow opacity .5, the observation was 127 versus 191 from the product model. Behavior varies across the matrix; do not infer a universal formula or change the PowerPoint claim based solely on this build. A changed shadow-distance XML negative control was rejected by the inspector.

To reproduce, build the workspace, create a new empty output directory, run `node scripts/prepare-shape-shadow-matrix.mjs <dir>/matrix.pptx`, export it with a named LibreOffice build using an isolated user profile, and rasterize the resulting PDF with `pdftoppm -png -r 72 <dir>/matrix.pdf <dir>/page`. Run `python3 scripts/research/oracles/shape-shadow-matrix.py <dir>` to check the input and print the measured record. The generator refuses to overwrite the PPTX. Different application versions or rasterizers may yield different values.
