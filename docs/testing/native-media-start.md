# PowerPoint audio start timing observation

PowerPoint for Mac 16.104 opened the [mixed-media baseline](../../tests/fixtures/powerpoint-mixed-av.pptx), containing two videos and two one-second PCM audio objects. The second audio object (shape ID 5) originally used “In Click Sequence.” Its Playback menu was changed to “Automatically” and saved as the [automatic sample](../../tests/fixtures/powerpoint-audio-start-auto.pptx); that sample was then changed to “When Clicked On” and saved as the [object-click sample](../../tests/fixtures/powerpoint-audio-start-object-click.pptx). Each resulting file was closed and reopened in the same PowerPoint version; the selected audio object's Playback menu still showed the chosen setting. The retained copies replace the last-modifier field with `PPTKit fixture`; they are not byte-identical to the original saves.

The [independent ZIP/XML verifier](../../scripts/research/verify-media-start.py) checks media hashes and direct relationships, timing ID uniqueness, all four play targets, the two video pause targets, and the structure of the changed audio effect. The [negative controls](../../scripts/research/test_media_start.py) alter the effect type, delay, click target, timing ID and media bytes. These checks run in `pnpm test:timing-research`.

In the baseline, shape 5 is a `clickEffect` in a separate main-sequence group. In the automatic sample, it becomes an `afterEffect` in the same main-sequence group as shape 4, with an enclosing 1000 ms delay. Shape 4's command duration is also 1000 ms. This supports the inference that the observed automatic setting is sequenced relative to the previous effect; it does not prove that all automatic media starts at slide entry. In the object-click sample, shape 5's play command moves to an `interactiveSeq` triggered by `onClick` on shape 5. The other three play targets remain in the main sequence, and the two videos retain separate pause commands.

This is one mixed slide and one edited audio object. Actual slideshow timing, audible playback, re-entry, the first or only media object, multiple automatic objects, video start settings and other PowerPoint versions remain unverified. These observations are research evidence, not an implemented authoring or source-save contract. Trimming and animation-triggered playback are not covered by these samples.
