# Vertical writing mode matrix

The [Open XML SDK lists seven direction values](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.textverticalvalues?view=openxml-3.0.1). The [body attribute](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.bodyproperties.vertical?view=openxml-3.0.1) and [table cell attribute](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.tablecellproperties.vertical?view=openxml-3.0.1) are distinct locations. This fixture puts the same mixed Japanese/Latin text in a shape text body, a cell using `tcPr/@vert`, and a cell using `bodyPr/@vert`. A visible label distinguishes each mode.

```sh
node scripts/research/prepare-vertical-writing.mjs
python3 scripts/research/patch-vertical-writing.py
```

Current content import projects all seven slides and retains the patched package byte-for-byte on no-op save. Import reports all fourteen body attributes as unmapped and reports the four East Asian, Mongolian and WordArt cell property values as unmapped. The existing cell property path already recognizes horizontal, 90° and 270° values; a text body has no equivalent projection yet. The matrix SHA-256 is `31a4e15c0459e681c7bbc25c9e0bd54c93fd43901d51f3c72fc7cead0d026744`.

This is a source/import baseline. Native display, axis and glyph orientation, alignment, and cell attribute precedence have not been observed using this matrix. A quarter-turn is separate from East Asian vertical writing, where individual characters can have different orientations.

PowerPoint for Mac opened the matrix without showing a repair dialog. All seven pages were selected by number and captured in slideshow view. The [pixel checker](../../scripts/research/oracles/vertical-writing-pixels.py) requires distinct visible page labels and checks the ink axis and side separately for the three text owners. The shape and the `tcPr/@vert` cell are horizontal for `horz` and vertically arranged for every other mode. In this sample, `vert`, `eaVert`, and `wordArtVertRtl` place ink toward the right; `vert270`, `mongolianVert`, and `wordArtVert` place it toward the left. The `bodyPr/@vert`-only cell remains pixel-identical to the horizontal control on all seven pages. This supports treating the cell property as the effective owner in this fixture; a conflicting pair of explicit declarations was not tested.
