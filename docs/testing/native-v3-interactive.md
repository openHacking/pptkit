# PowerPoint merged-table character-save control

This named PowerPoint 16.104 control advances IMP-09.2.5 for one mixed two-slide source. The source and V3 candidate were copied after matching the [prior table-save evidence](table-save-evidence.json); original artifacts were not modified. The sample includes a separate two-cell control table, a 2×2 merged anchor in a three-column table, a right-hand anchor at physical row 2/column 3, slide/notes controls, a chart and workbook, a shared image and injected unknown content.

In PowerPoint's UI, ` UIA` was appended to the merged anchor and ` UIB` to the right-hand anchor; an actual save and three distinct Save As, close and exact-reopen rounds followed. Independent XML checks retain both target texts, the three-column grid, row heights, merge occupancy, controls, slide↔notes relationships, chart cache, workbook and shared image bytes. PowerPoint changed the lexical attributes on merge continuations while preserving this named occupancy. It retained the named opaque slide extension but removed the orphan and the injected unknown cell attribute. Image and workbook parts were renamed; this is application behavior, not a PPTKit source-save loss. Other unknown references and app versions remain unverified.

Initial interactive and third-reopen slide PDFs have equal pixels, drawings and image records on both pages. Their first-page raw text traces differ; glyph identity and style agree, with maximum observed origin deviation about 0.0199 PDF points. The second page's complete records match. Text wraps in the narrow cells; this is an observed layout, not a claim about all overflow cases.

PPTKit then reimported the third PowerPoint copy using `text-runs-v3` and changed those two existing anchors. The public change report identifies physical row 1/column 1 and row 2/column 3. Independent ZIP/XML comparison confirms an unchanged part set and exactly those two text atoms changed in one slide payload; all other payloads are byte-identical. PowerPoint opened this candidate and completed three further distinct Save As, close and exact-reopen rounds. Initial and final candidate PDFs match in pixels, complete text traces, drawings and image records. The orphan and cell attribute already removed by PowerPoint were not restored.
