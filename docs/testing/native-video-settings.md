# Native video playback settings

PowerPoint for Mac 16.104 was used to modify the first of two shared MP4 video objects from `pptkit-video-auto.pptx`. The saved samples `powerpoint-video-settings-low.pptx` and `powerpoint-video-settings-mute.pptx` contain, respectively, low volume and low volume with mute, both with loop and rewind enabled. The second object retains high volume and neither option. In the XML the first uses `vol="20000"`, optional `mute="1"`, `repeatCount="indefinite"` and `fill="remove"`. The samples retain their original automatic sequence, in which the second automatic effect follows the first looping effect; this is not projected as a valid main sequence.

PPTKit exports per-object `playbackVolume`, `muted`, `loop`, and `rewindAfterPlayback`. Mute and volume are independent so unmuting does not lose the prior setting. The supported volume values correspond to the observed PowerPoint low, medium, and high values; other values and unsupported direct timing structures are not projected. Fresh export rejects an automatic effect following an indefinitely looping main effect. Native and generated settings, invalid input, repeated fresh imports and exports, original-byte no-op save, and Node/browser import parity are covered by automated tests.

The samples were saved through PowerPoint's Playback controls. A separately generated PPTKit file opened in PowerPoint for Mac 16.104 without a visible repair prompt; its Playback controls showed mute, loop, and rewind enabled. Actual video and sound playback, re-entry, other PowerPoint versions and applications, and source-preserving edits to these settings have not been verified. SVG remains a static poster.
