# 幻灯片能力实施子任务

本文细化 [Implementation Backlog](implementation-backlog.md) 的主任务，尤其是导入、round-trip、SmartArt 与动画。未勾选的子任务均为 **待完成**，不表示已有 API 或兼容性承诺；勾选项必须链接验证证据。现有实现证据见 [能力矩阵](capability-matrix.md)。

## 执行与验收规则

- 阅读顺序：先按[近期执行计划](next-delivery-plan.md)选择工作包，再在本文领取稳定 ID。本文的完整覆盖范围用于长期排队；下一轮不要求同时实现所有条目。
- 子任务采用 `主任务 ID.序号`，继承主任务的优先级、负责人和依赖；表中额外依赖也必须满足。父任务仅在其必需子任务及原有验收标准全部满足后关闭。
- 每个实现子任务交付代码、正反例 fixture、公共 API/示例和兼容性说明。研究任务交付决策记录与实验依据，不能据此宣称功能已实现。
- 每个对象分别记录：创建、导入、编辑、预览、导出、原样保存、编辑后保存。结果使用 editable / preserved / fallback / unsupported，禁止用一个“支持”覆盖所有操作。
- 所有降级或丢失报告包含 slide/element ID、源 part/path、原因、影响及可选处理；发生丢失的保存必须由调用方显式选择策略，不静默吞掉内容。
- 未知 OOXML 及其资源依赖归格式层；Core/IR 保持格式无关。不得为 SmartArt、动画等元素类别单独拆出无必要的包。
- 普通功能通过单元、包集成、公共消费者与相关视觉回归；原生编辑/播放/round-trip 声明额外需要具名应用版本的实际证据。未验证的应用标记 untested。
- 大子任务继续拆为 `主任务.子任务.切片`，如 `IMP-06.1.1`。三级切片沿用上级归属、优先级及依赖；额外依赖列只列新增闸门。切片的局部证据不自动关闭上级任务，也不扩大其他切片的支持范围。
- 跨能力依赖只引用所需阶段：媒体清理可以注入离页事件验证，不等待完整放映导航；完整媒体/动画/导航组合另由 ADV-12.5 验收。不得让基础功能等待包含自身的集成任务。
- **候选实现不等于验收完成**：工作区存在代码、测试或 API 草案时，先登记“候选实现 / 待收口”和剩余验证，再决定是否继续扩展。`text-runs-v1` 归入 IMP-09.2.1.1；2026-10-25 已有[完整自动化验证记录](execution-record.md#direct-text-run-preservation-saves-2026-10-25)，仍不据此补签 PowerPoint/交互或父项完整兼容结论。

## 范围选择与完成口径

完整 TODO 是候选能力全集；v1 必需范围由 STB-01 决定。建议先把现有对象的导入、引用维护和编辑保存做成闭环，再扩更多对象族；下面只提供选择标准，不提前替 STB-01 冻结版本范围。

- **先闭环**：常用文字/形状/图片/表格/现有图表、主题继承、未知内容保留、独立比较器及首批编辑保存。每种操作都有明确的支持、拒绝或损失报告。
- **按子集发布**：具名 SmartArt 布局、具名媒体编码、具名切换/动画效果和输出适配器。通过一个子集后再增加覆盖，未验证项不进入支持声明。
- **保留研究结果**：更多 SmartArt、专项图表、Morph/Zoom、公式、3D、墨迹、嵌入对象及保护/签名。ADR 可以决定暂缓；暂缓不等于实现完成。
- **防止重复计数**：父项描述范围，叶子任务描述实现或证据。工作包、覆盖地图和样本计划均为导航，不另设完成状态；同一份证据可以被引用，但不能用来扩大未经验证的保证。

## 每个任务的交付记录模板

## 关闭任务前的反向审查

- **假可编辑**：是否只是图片/形状组却标为 SmartArt，或只写出 XML 就宣称可播放？必须有实际编辑/播放证据。
- **假无损**：是否只比较可见截图，漏掉未知关系、备注、宏、动画或共享资源？必须同时比语义、关系闭包及二进制摘要。
- **结构修改破坏引用**：删除/复制后是否留下链接、评论、时间线或图表悬空引用？必须覆盖破坏性操作和失败后重试。
- **环境依赖失真**：缺字体/编解码器、浏览器与 Office 差异是否被掩盖？必须固定环境并公开 unsupported/untested 范围。
- **范围失控**：研究结论是否被误勾为产品功能，主任务是否在子项未验收时关闭？完成记录必须逐项链接证据。
